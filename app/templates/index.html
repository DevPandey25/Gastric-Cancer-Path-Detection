    Module 07

    Nuclei Detection & Cellular Morphology

    Exploratory
    Candidate Detection Caveat: The classical Ruifrok HED-watershed algorithm extracts candidate objects, NOT manually validated nuclei. The exploratory pilot evaluated 64 patches (3,895 candidate objects). Deep learning models (Cellpose, StarDist, HoVer-Net) are blocked due to missing pretrained weights in the offline sandbox. No confirmed cell-type labels are fabricated.

    Evaluated Pilot Patches

    64 image patches (8 balanced samples per GCHTID class).

    Total Candidate Objects

    3,895 segmented candidate cellular instances (60.86 ± 38.4 per tile).

    Detector Methodology

    Ruifrok Color Deconvolution → Hematoxylin OD → Marker Watershed.

    Module 08

    Spatial Graph and GNN Engine

    Exploratory
    Geometric Proximity Disclosure: Candidate objects form graph nodes connected by symmetric k-nearest-neighbor edges (k=6, Euclidean distance, bidirectional with self-loops) over 16-D normalized morphology and spatial coordinate node features. These represent geometric Euclidean proximity on classical candidates, NOT verified biological cellular communications.
    Model Name Architecture Type Parameters Balanced Accuracy Accuracy Macro F1

    Empirical Finding

    Among graph architectures, GCN achieved highest performance (balanced acc 21.25%). However, the non-graph Morphology MLP baseline (global graph pooling) outperformed all GNNs (23.75% balanced accuracy), demonstrating that spatial graph message passing does not improve over aggregate morphology descriptors on this 64-patch pilot.

    Module 09

    Whole-Slide Image Infrastructure & MIL Framework (Infrastructure Only)

    0 Genuine WSIs
    Scientific Integrity & Data Availability Disclosure: An exhaustive audit of the repository confirmed 0 genuine Whole-Slide Images (.svs, .ndpi, .mrxs) and zero slide-level clinical labels. The WSI pipeline in this repository represents an infrastructure-only engineering implementation verified solely against a synthetic pyramidal test fixture (test_pyramid.tiff). Synthetic test fixtures are NOT patient slides and must NOT be interpreted as clinical whole-slide analysis. Supervised Multiple Instance Learning (MIL) model training and patient-level slide inferences are strictly withheld.

    Pipeline Architecture

    Status: Software architecture ready; awaiting genuine WSI cohort.

    Verified using synthetic 4-level pyramidal fixture (test_pyramid.tiff) generating 64 mock tiles across downsample factors 1x, 2x, 4x, 8x.

    Fixture: Synthetic test mock only — NOT clinical histology.
