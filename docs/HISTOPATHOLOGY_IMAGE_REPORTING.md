## 1. Principles of Image Presentation Integrity

Histopathology images represent primary scientific evidence in computational pathology. GastricPath AI enforces strict presentation invariants:
1. **Zero Optical Fabrication:** If optical magnification (e.g., 20x, 40x), numerical aperture, physical pixel size ($\mu\text{m/pixel}$), or calibrated scale bars are not recorded in genuine image metadata headers, they must be marked **`[Uncalibrated / Unknown]`**. Fabricating arbitrary scale bars (such as "50 $\mu\text{m}$") without physical calibration metadata is strictly prohibited.
2. **Cryptographic Provenance:** Every ingested tissue image is assigned a persistent cryptographic SHA-256 hash. The original image bytes are preserved without lossy re-encoding or unrecorded cropping.
3. **No Synthetic Tissue Graphics:** The platform never displays synthetic diffusion images or generative drawings as patient specimens.
4. **Attribution Boundaries:** Heatmaps (Grad-CAM, Integrated Gradients) represent algorithmic feature sensitivity under specific mathematical loss functions; they do not establish causal human cellular biology.
5. **Patch vs. Patient Distinction:** Patch-level model outputs from $224 \times 224$ pixel crops reflect local histological tissue characteristics (e.g., presence of atypical epithelium, stroma, or mucin), not whole-slide tumour burden, anatomical cancer staging, or patient diagnosis.

## 2. Multi-Panel Figure Layout Specification

Figures are structured in standardized 3-to-4 panel scientific layouts:

```
+-----------------------------------------------------------------------------------------+
| (A) ORIGINAL H&E PATCH         | (B) PREDICTED PROBABILITY       | (C) GRAD-CAM SALIENCY |
|                                |                                 |                       |
|   Genuine Microscopic Crop     |   Horizontal Bar Chart          |   Spatial Heatmap     |
|   224 x 224 pixels             |   8-Class Tissue Decomposition  |   Feature Activation  |
|   Uncalibrated Optical Scale   |   TUM / STR / LYM / MUC ...     |   Attribution Overlay |
|                                |                                 |                       |
+-----------------------------------------------------------------------------------------+
Caption: Figure GP-01: Multi-panel characterization of gastric adenocarcinoma patch...
```

### Panel Elements:
- **Panel A (Original Histology):** Displayed at native aspect ratio without artificial contrast boosting or synthetic sharpening.
- **Panel B (Classification Distribution):** Horizontal bar chart of the 8 classes (`ADI`, `DEB`, `LYM`, `MUC`, `MUS`, `NOR`, `STR`, `TUM`) generated by the certified `GastricCancerRNN` baseline model (`gastric_rnn_classifier.pt`, SHA-256: `65369ef6...`).
- **Panel C (Attribution Heatmap):** Saliency map depicting feature attribution across the $4 \times 4$ spatial sub-tile grid, with explicit attribution limitations.

## 3. Supported File Formats and Extraction Criteria

| Format | Extension | Ingestion Protocol | Provenance Extracted |
|:---|:---|:---|:---|
| **PNG** | `.png` | Direct Pillow lossless ingest | Width, height, bit depth, SHA-256 |
| **JPEG** | `.jpg`, `.jpeg` | Lossless stream read | Dimensions, EXIF header audit, SHA-256 |
| **TIFF** | `.tif`, `.tiff` | Baseline multi-page inspection | Layer count, resolution tags, SHA-256 |
| **Whole-Slide Images** | `.svs`, `.ndpi` | OpenSlide level-0 pyramidal reader (when available) | Level-0 dimensions, downsample factors, slide metadata |

## 4. Scientific Captions and Limitations Template

Every generated figure in Mode A (Case Dossier), Mode B (Image Atlas), or Mode C (Research Manuscript) must append the mandatory interpretation boundary statement:

> *"Interpretation boundary: Patch-level model outputs from an experimental research classifier; not a clinical pathology diagnosis, whole-slide assessment, or cancer stage prediction. Uncalibrated microscopic scale."*
